# ⚡ AI Script & Content Generator

An interactive web application built with **Streamlit** and the **Google GenAI SDK** that generates high-quality YouTube video scripts, social media posts, and study summaries using Gemini models.

## 🚀 Features
- **Multi-format Generation**: YouTube scripts, social posts, summaries, and guides.
- **Powered by Gemini API**: Fast and context-aware responses.
- **Clean UI**: Streamlit-driven interface for instant results.

## 🛠️ Tech Stack
- Python
- Streamlit
- Google GenAI SDK (`gemini-2.5-flash`)
